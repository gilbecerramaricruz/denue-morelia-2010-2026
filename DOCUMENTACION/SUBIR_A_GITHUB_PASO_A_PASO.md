# Subir este paquete a GitHub desde el navegador

1. Iniciar sesión en GitHub.
2. Crear un repositorio nuevo.
3. Nombre sugerido: `denue-morelia-2010-2026`.
4. Descripción sugerida: `Reconstrucción histórica y homologación longitudinal del DENUE de Morelia, Michoacán, 2010–2026.`
5. Elegir inicialmente **Private** si todavía se desea revisión del profesor antes de hacerlo público.
6. No agregar README, .gitignore ni licencia al crear el repositorio: este paquete ya incluye README y .gitignore.
7. Abrir el repositorio recién creado y elegir **Add file > Upload files**.
8. Descomprimir este ZIP en Windows.
9. Arrastrar al área de carga **el contenido de la carpeta**, no el ZIP.
10. Esperar a que aparezcan los archivos y carpetas.
11. En el mensaje de commit escribir: `Versión inicial reproducible del análisis DENUE Morelia 2010-2026`.
12. Confirmar la carga.

Antes de hacerlo público, revisar el README y comprobar que no se hayan agregado archivos de `00_ORIGINALES` ni `01_MORELIA_LIMPIO`.
