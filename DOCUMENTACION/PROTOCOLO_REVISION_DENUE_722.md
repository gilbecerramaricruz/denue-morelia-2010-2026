# Protocolo de revisión manual — piloto DENUE 2013–2015

**Estado:** borrador para comentarios del profesor. Se propone utilizar **una revisora principal**, no dos evaluaciones independientes ficticias.

## Qué se revisa

Cada expediente corresponde a un establecimiento de referencia de uno de los cortes. Se muestran todas las parejas candidatas disponibles, sin enseñar las decisiones provisionales anteriores. Puede ser necesario buscar también fuera de esos candidatos y fuera del subsector 722.

## Dictámenes permitidos

| Dictamen | Qué significa |
|---|---|
| `PAR_PROPUESTO` | Una pareja específica cuenta con evidencia suficiente para proponerla; requiere justificación y posterior adjudicación. |
| `INDETERMINADO` | Los datos no permiten decidir con confianza, o dos o más alternativas son razonables. |
| `NINGUNO_JUSTIFICABLE_EN_LISTA` | Ningún candidato presentado ofrece sustento suficiente; **no** significa cierre. |
| `PAR_FUERA_DE_LISTA` | Una búsqueda ampliada encontró una propuesta no incluida originalmente. |
| `BUSQUEDA_AMPLIADA_PENDIENTE` | Aún falta revisar posibles correspondencias fuera del conjunto de candidatos. |

## Evidencia que debe anotarse

Se registra si el nombre es distintivo o genérico; concordancia de domicilio incluyendo interior/local; cambios de teléfono y si se comparte; desplazamientos de coordenadas; clasificación SCIAN original; posibles sucursales y contradicciones; y, cuando existan, **fuentes externas fechadas**. Una evidencia aislada no basta para confirmar continuidad. Si falta información, se registra como **no comparable**.

## Cómo evitar sesgos

La revisora trabajará sin mostrarle las decisiones preliminares del algoritmo. Deberá considerar alternativas y la opción de no vincular. El piloto de 55 expedientes sirve para afinar los criterios; P001 y P002 ya se analizaron conjuntamente, por lo que no forman parte de una validación ciega. **La muestra definitiva de evaluación se seleccionará después de congelar el algoritmo y sin reutilizar los expedientes usados para diseñarlo.**

Con una sola revisora pueden evaluarse los enlaces, pero no se puede medir acuerdo entre revisores. Las conclusiones deberán reconocer esa limitación, las fuentes consultadas, los casos indeterminados y los posibles errores de referencia.

## Separar identidad de demografía

El dictamen sólo busca determinar si dos registros podrían representar el mismo establecimiento. No declara nacimiento, muerte, actividad ininterrumpida ni supervivencia entre dos cortes.

**Archivos de trabajo individuales:** permanecen locales y fuera de este repositorio. No incluir números de teléfono, fichas completas ni evaluaciones personales en GitHub público sin revisión previa.
